# 🎓 Student Personal Portal

A simple and organized **Student Personal Portal** project built to manage student access, authentication, and dashboard-based interaction in a structured way.  
This project follows a separated folder architecture with **control**, **model**, and **view** components, making it easier to understand and maintain.

---

## 📌 Project Overview

The **Student Personal Portal** is designed as a web-based system where students can access a personal area through registration and login.  
After authentication, users can enter their dashboard and interact with the portal in a more organized way.

This project is useful for practicing:

- basic web application flow
- login and registration system
- dashboard navigation
- structured project architecture
- PHP-based portal development

---

## ✨ Main Features

- ✅ Landing page
- ✅ Student registration page
- ✅ Student login page
- ✅ Personal dashboard
- ✅ Logout functionality
- ✅ Organized MVC-style folder structure
- ✅ Separated frontend and backend logic
- ✅ Easy to expand for future academic features
